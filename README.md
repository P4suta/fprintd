# Fprintd

Rust fingerprint service compatible with the fprintd D-Bus interface.

## Installation

```sh
# Install the hardware-free demo from source.
git clone https://github.com/P4suta/fprintd.git
cd fprintd
cargo install --locked --path crates/fprint-cli
```

## Usage

```sh
fprint demo
```
